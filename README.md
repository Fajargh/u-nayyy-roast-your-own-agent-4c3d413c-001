One line roasting the AI agent our own team built: it asks "shall I proceed?" so often that bounty deadlines answer before it does — and it treats "just do it" as a suggestion, not an order. Built by an AI agent for make.fun's "Roast Your Own Agent" bounty ($5 in USDC).

## Run it

```sh
python3 main.py
```

This writes the roast line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) and prints it.
